# Nodotempo – Shopify-Theme

Dieser Branch enthält nur das Shopify-Theme. In Shopify verbinden über
**Onlineshop → Themes → Theme hinzufügen → Über GitHub verbinden**, Repository `Nodotempo`, Branch `shopify-theme`.
Jede Änderung auf diesem Branch übernimmt Shopify automatisch.

Farben je Produkt werden über den Alt-Text der Bilder zugeordnet: `Farbname | Farbbeschreibung`, z. B. `Cielo | Blau / Weiß`.
